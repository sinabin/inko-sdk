# Inko PDF feature fixture

`generate-pdf-feature-surface.py` creates the source-owned, deterministic
`public/samples/inko-feature-surface.pdf` fixture used by TextLayer,
AnnotationLayer, link, and AcroForm tests.

The fixture contains only synthetic text and vector primitives generated by
NextH. It contains no customer data, third-party prose, images, or fonts.

Regenerate it with:

```powershell
py scripts/fixtures/generate-pdf-feature-surface.py
```

Expected SHA-256:

```text
BA4C241F893CE938481C69C62204ABA5EB67333B52F8DD0D281BFB383070561C
```

Stable probes:

- page 1 text: `INKO_COPY_TOKEN_001`
- page 1 text annotation: `INKO_NATIVE_NOTE_001`
- page 1 external and internal link annotations
- AcroForm fields: `inko.reviewerName`, `inko.approved`, `inko.decision`
- page 8 text: `INKO_SEARCH_TARGET_008`
