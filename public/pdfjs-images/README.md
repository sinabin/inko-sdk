# PDF.js annotation icons

This directory contains the 11 native annotation icons loaded dynamically by
PDF.js annotation layers.

- Upstream package: `pdfjs-dist@5.4.624`
- Upstream paths: `web/images/annotation-*.svg`
- Copyright: Mozilla Foundation and PDF.js contributors
- License: Apache License 2.0
- Preserved license: `LICENSE.pdfjs-dist`
- Integrity manifest: `manifest.json` (SHA-256 of every copied SVG and license)

The SVG and license files are copied byte-for-byte from the locked npm package.
When `pdfjs-dist` is upgraded, replace all files together and regenerate the
manifest; do not edit individual icons locally.
